## 🏃 Quick Start (Local Setup)

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- (Optional) Live Server extension for VS Code or any local server

### Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jayanth-kumar-A/MY-PORTFOLIO.git
   cd MY-PORTFOLIO
   ```

2. **Open in browser:**
   - **Option A:** Double-click `index.html` to open directly
   - **Option B:** Use Live Server (VS Code extension)
     - Right-click `index.html` → "Open with Live Server"
     - Visit `http://localhost:5500` (or your server port)

3. **That's it!** No build steps, no dependencies.

## 🚀 Deployment (GitHub Pages)

Your portfolio is already set up for GitHub Pages! It's live at:
```

```

### To enable/verify GitHub Pages:
1. Go to **Settings → Pages**
2. Ensure **Source** is set to `main` branch → `/ (root)`
3. Click **Save**
4. Your site will be live in a few seconds!

## 🔧 Customization Guide

### Change Colors
Edit the CSS variables in `index.html` (lines 10-20):
```css
:root {
  --bg: #080c10;           /* Background */
  --accent: #00d4ff;       /* Primary color (cyan) */
  --accent2: #7c3aed;      /* Secondary color (purple) */
  --text: #e8edf2;         /* Text color */
  --muted: #5a7080;        /* Muted text */
  --green: #00e5a0;        /* Green accent */
}
```

## 🐛 Troubleshooting

| Issue | Solution |
|---|---|
| **Fonts not loading** | Check internet connection; Google Fonts CDN may be blocked in your region |
| **Animations not smooth** | Update browser to latest version; clear cache |
| **GitHub Pages not updating** | Wait 1-2 minutes; hard refresh browser (Ctrl+Shift+R) |
| **Contact form doesn't send** | Currently shows alert; integrate Formspree or another backend service |
